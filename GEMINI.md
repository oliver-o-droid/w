# Contexto del Proyecto

- Este proyecto (`webGit`) corresponde al repositorio GitHub `w` (`https://github.com/oliver-o-droid/w.git`).
- Se utiliza para alojar y servir **webs estáticas** mediante GitHub Pages en: `https://oliver-o-droid.github.io/w/(nombredelacarpeta)/`.
- Para desplegar o actualizar una web en este entorno, es necesario hacer commit y subir los cambios a GitHub (`git push`).
- Para proyectos web dinámicos con persistencia y guardado de ficheros en el servidor, se utiliza habitualmente la carpeta `../w/` (enlace al servidor propio).
